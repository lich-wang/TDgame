# 🏗️ 霍尔木兹狂想曲 — 架构设计

## 一、技术选型

| 层面 | 选择 | 理由 |
|------|------|------|
| 渲染 | Canvas 2D API | 塔防游戏需大量精灵绘制，DOM 性能不足 |
| 语言 | ES6+ 原生 JS | 零依赖，浏览器即开即玩 |
| 样式 | CSS3 | 仅用于 UI 面板、弹窗等 DOM 元素 |
| 模块化 | 全局命名空间 + IIFE | 简单场景无需打包工具 |

## 三、模块职责

| 文件 | 职责 | 对外接口 |
|------|------|---------|
| `data.js` | 全局常量定义：塔/敌人/波次/播报/事件/地图 | `TOWER_TYPES`, `ENEMY_TYPES`, `WAVES`, `MAP`, `STRIKE_OPTIONS` 等 |
| `economy.js` | 绿纸/声望/制裁/通胀状态管理 | `class Economy` — `addMoney()`, `spend()`, `getInflationMultiplier()`, `onWaveEnd()` |
| `projectile.js` | 弹道飞行物（炮弹/导弹/无人机） | `class Projectile` — `update(dt)`, `draw(ctx)` |
| `enemy.js` | 7种敌人类型的AI和绘制 | `class Enemy` — `update(dt)`, `takeDamage()`, `draw(ctx)` |
| `tower.js` | 6种塔的攻击逻辑/水雷/雷达 | `class Tower` — `update(dt, enemies, projectiles)`, `draw(ctx)`, `upgrade()` |
| `map.js` | Canvas 地图绘制（天空/水道/基地） | `drawMap(ctx, gameState)` |
| `events.js` | 按波次概率触发随机事件 | `triggerRandomEvent(game)` |
| `ui.js` | DOM 元素更新和塔按钮初始化 | `updateUI(game)`, `initTowerButtons()` |
| `game.js` | 游戏主循环、状态机、波次管理、交互 | `const game = new Game()` — `start()`, `update(dt)`, `render()` |

## 四、数据流

```
帧循环 (requestAnimationFrame)
  │
  ├─► game.update(dt)
  │     ├─► 检查波间延迟 / 跳过波
  │     ├─► 从 spawnQueue 生成 Enemy
  │     ├─► Enemy.update(dt)
  │     │     └─► 沿路径移动 | 航母 call game.spawnFly()
  │     ├─► Tower.update(dt, enemies, projectiles)
  │     │     ├─► 雷达: 修改 enemy.revealed
  │     │     ├─► 水雷: 碰撞检测 + ExplosionEffect
  │     │     └─► 攻击: new Projectile() → projectiles[]
  │     ├─► Projectile.update(dt)
  │     │     └─► 追踪目标 → 命中时 enemy.takeDamage()
  │     ├─► 清理死敌人/过期投影物
  │     │     └─► enemy.alive=false: Economy.addMoney(bounty)
  │     ├─► OilTanker 更新 & 碰撞
  │     │     └─► 安全到达: Economy.addOilReward()
  │     ├─► 检查波次结束 / 游戏失败
  │     └─► updateUI(game) [写 DOM]
  │
  └─► game.render()
        ├─► drawMap(ctx, gameState)     [静态背景]
        ├─► OilTanker.draw(ctx)         [油轮]
        ├─► Enemy.draw(ctx)             [敌人+血条]
        ├─► Projectile.draw(ctx)        [弹道+爆炸]
        ├─► Tower.drawMines(ctx)        [水雷]
        └─► Tower.draw(ctx)             [塔+射程圈+星级]
```

## 五、状态机

```
        ┌─────────┐
        │  menu   │  ← 初始 / 游戏结束后
        └────┬────┘
             │ start()
        ┌────▼────┐       _startNextWave()      ┌──────────────┐
        │ playing │ ───────────────────────────► │ waveActive=  │
        │         │ ◄──── wave_clear 状态过5s ── │ true         │
        └────┬────┘                              └──────────────┘
             │
      ┌──────┴──────┐
      │             │
  声望≤0         波次=20
      │             │
  ┌───▼───┐    ┌───▼───┐
  │ defeat│    │victory│
  └───┬───┘    └───┬───┘
      │             │
      └──► modal ──► menu
```

状态说明：
- `menu`: 开始画面，等待用户点击
- `playing`: 游戏运行中（波间等待也属于 playing）
- `wave_clear`: 过渡中（5秒），用于标识
- `victory`/`defeat`: 弹窗显示结果

## 七、关键设计决策

1. **全局 game 单例**：通过 `const game = new class Game{}()` 立即实例化，所有模块通过 `game.xxx` 方法交互
2. **塔位固定**：海岸线 8×2 共16个固定槽位，不可自由放置
3. **敌人沿水平线移动**：所有海上敌人沿 `PATH_Y=340` 水平移动，空中敌人浮动在上方
4. **水雷特殊机制**：水雷塔定期自动在水道随机位置生成水雷实体，碰撞触发爆炸
5. **雷达塔**：不攻击，仅揭露隐身子弹 + 提供伤害加成光环
6. **经济系统**：绿纸(建塔/升级/出击) + 声望(解锁威慑，为0即失败) + 油轮(绿纸来源)
