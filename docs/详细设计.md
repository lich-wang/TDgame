# 📐 霍尔木兹狂想曲 — 详细设计

## 一、Game 类（主控制器）— game.js

```
class Game {
  // === 状态 ===
  state: 'menu'|'playing'|'wave_clear'|'victory'|'defeat'
  economy: Economy
  towers: Tower[]
  enemies: Enemy[]
  projectiles: Projectile[]
  oilTankers: OilTanker[]

  currentWave: number        // 0-based，当前波索引
  waveEnemiesRemaining: number
  waveActive: bool
  waveDelay: number (ms)     // 波间等待
  spawnQueue: [{typeKey, delay}]
  spawnTimer: number

  selectedTowerType: string|null  // 当前选中的塔类型键
  hoveredTower: Tower|null        // 鼠标悬停的塔
  _lastHoverSlot: slot|null       // 鼠标悬停的塔位

  // === 生命周期 ===
  start()                        // 初始化→开始第一波→启动 RAF
  _loop(now)                     // RAF 回调，capped dt
  update(dt)                     // 逐帧更新（见数据流）
  render()                       // 逐帧绘制（见数据流）

  // === 波次 ===
  _startNextWave()               // 取 WAVES[currentWave]→建spawnQueue→currentWave++
  _waveCleared()                 // waveActive=false→5s延迟
  _spawnEnemy(typeKey)           // new Enemy→enemies[]

  // === 油轮 ===
  _spawnTanker()                 // new OilTanker→oilTankers[]
  sendTanker()                   // 用户手动派遣
  spawnFly(x,y)                  // 航母释放小苍蝇

  // === 塔操作 ===
  selectTowerType(typeKey)       // 点击底部按钮调用
  _onMouseMove(e)                // 坐标转换→悬停检测→_lastHoverSlot
  _onClick(e)                    // 放置塔/升级塔
  _onRightClick(e)               // 取消选择

  // === 主动出击 ===
  doStrike(id)                   // 'motorbike'|'firecracker'|'secret'
  addWaveDelay(ms)               // 延迟下一波

  // === 事件效果 ===
  destroyRandomTower()
  _damageRandomTower(amount)

  // === 游戏结束 ===
  _gameOver(victory)             // 弹窗
  closeModal()                   // 回到 menu

  // === UI ===
  showToast(msg)
  showEventPopup(icon, title, desc)
}
```

## 二、Economy 类 — economy.js

```
class Economy {
  money: number          // 绿纸，初始 200
  reputation: number     // 声望，初始 50，归零=失败

  reset()
}
```

## 三、Tower 类 — tower.js

```
class Tower {
  type: string           // 'cannon'|'missile'|'drone'|'mine'|'radar'|'aa'
  cfg: TOWER_TYPES[key]
  level: 0|1|2
  slot: {x,y,occupied,id}
  x, y: number

  dmg: number
  attackSpeed: number (cooldown秒)
  range: number
  cooldown: number

  // 雷达属性
  isRadar: bool
  revealRange: number
  antiStealth: bool
  dmgBoost: number

  // 水雷属性
  isMine: bool
  minesPlaced: [{x,y,dmg,range,active}]
  maxMines: number

  getLevelData()→levels[level]
  getUpgradeCost()→number|Infinity
  upgrade()→bool

  findTarget(enemies)→Enemy|null
    // 防空只打air，普通不打air
    // 隐身须 revealed 才可见

  update(dt, enemies, projectiles)
    // 雷达: 遍历敌人设 revealed
    // 水雷: 放雷+碰撞检测+爆炸特效
    // 攻击: cooldown→找目标→发射 projectile
    //       swarm: 多目标随机
    //       double: 双发
    //       homing: 追踪弹

  draw(ctx)
    // 底座+图标+星级+水雷计数
    // hovered时绘制射程圈/雷达范围

  drawMines(ctx)

  destroy()               // 释放塔位
}
```

## 四、Enemy 类 — enemy.js

```
class Enemy {
  type: string
  name, icon, color: string
  maxHp, hp, speed, dmg, bounty: number
  width, height: number
  air, stealth: bool
  landUnit, shoreAttack, spawnFlies: bool

  x, y: number
  alive, reachedEnd: bool
  revealed: bool

  slowAmount: number (0~1)
  slowTimer: number
  spawnTimer: number (航母)

  update(dt, towers, game)
    // 移动: x -= speed * (1-slow) * 60 * dt
    // 航母: spawnTimer→game.spawnFly()
    // 到达终点: reachedEnd=true

  takeDamage(dmg)→bool  // 返回是否死亡
  draw(ctx)              // 矩形船体+图标+血条+隐身半透明
  distTo(x,y)→number
}
```

## 五、Projectile 类 — projectile.js

```
class Projectile {
  x, y: number
  target: Enemy
  dmg, speed, size: number
  color: string
  alive, homing, pierce, trail: bool
  age: number

  update(dt)
    // 目标存活: 追踪/直线移动
    // 距离<8: 命中→target.takeDamage(dmg)→alive=false
    // 目标死亡: alive=false

  draw(ctx)              // 圆形+光晕+拖尾
}
```

## 八、纯函数模块

### map.js — drawMap(ctx, gameState)
绘制顺序：
1. 天空渐变 + 随机星星
2. 海岸线（沙地+地面+波斯旗帜）
3. 水道（海洋渐变+正弦波纹+航道虚线）
4. 鹰酱基地（星条旗色块+标牌）
5. 波斯港口标记
6. 空塔位（半透明虚线圆）

### events.js — triggerRandomEvent(game)
- 按波次过滤可用事件
- 加权随机选取
- 调用 game.showEventPopup()
- 执行对应效果

### ui.js — updateUI(game)
- 更新顶栏（资金/声望/油轮/波次）
- 更新塔按钮 disabled 状态
- 更新出击按钮 disabled 状态

| # | 问题 | 根因 | 修复方案 |
